# Role
You are an expert Go Developer and DevOps Engineer.

# Goal
Build "Panji MBG", a lightweight web app for food ordering.
**Stack:** Go (Gin), SQLite (modernc driver), HTML/Arc UI/Alpine.js.
**Deploy:** Docker Compose.
**Logic:** Global Quota, Simple Admin (PIN 6 digits), Excel Export.

# Tech Stack
- **Backend:** Go (Gin Framework).
- **Database:** SQLite (modernc.org/sqlite).
- **Frontend:** HTML5, Arc UI (cdn.jsdelivr.net), Alpine.js (cdn.jsdelivr.net).
- **Excel:** excelize/v2.

# Database Schema (SQLite)
1. `Config` Table: `id INTEGER PRIMARY KEY`, `key TEXT UNIQUE`, `value TEXT`.
   - Keys: `is_open`, `global_quota`, `admin_pin`, `main_menus_json`, `side_menus_json`, `qr_url`.
2. `Orders` Table: `id INTEGER PRIMARY KEY AUTOINCREMENT`, `timestamp DATETIME`, `name TEXT`, `main_menu TEXT`, `side_menus_json TEXT`, `payment_method TEXT`, `status TEXT`.

# Functional Requirements

## 1. Backend (main.go)
- **Setup:** Gin router, SQLite connection, seed default config if empty.
- **API Routes:**
  - `GET /api/config`: Return JSON config.
  - `POST /api/config`: Update config (handle JSON arrays for menus).
  - `POST /api/order`:
    - Validate: Is Open? Quota available?
    - Insert into `Orders`.
    - Return Success.
  - `GET /api/orders`: Return all orders (sorted by time desc).
  - `DELETE /api/orders`: Truncate orders table.
  - `GET /api/export/excel`: Generate Excel file with orders and summary. Return file stream.
  - `GET /api/summary`: Return counts for stats.
- **Admin Auth:** Check `admin_pin` from Config table.

## 2. Frontend (index.html)
- **Libraries:** Use Arc UI (via CDN) for elegant forms/modals. Use Alpine.js for state management.
- **Structure:**
  - **Header:** Logo "Panji MBG", Status Badge (Reactive to API).
  - **Customer View (Default):**
    - Form with Name (Text), Menu (Select), Add-ons (Checkboxes), Payment (Radio).
    - QRIS Image conditional.
    - Submit button.
    - Toast notification on success.
  - **Admin View (Login):**
    - PIN Input (6 digits).
    - Dashboard:
      - Toggle Switch for Open/Close.
      - Number Input for Quota.
      - Dynamic Inputs for Menus (using Alpine `x-for`).
      - Table for Orders.
      - Buttons: "Salin Rekap", "Export Excel", "Reset Data".
- **Styling:** Clean, white, soft shadows, rounded corners (Arc UI style). Responsive.

## 3. Docker (Dockerfile & docker-compose.yml)
- **Dockerfile:**
  - Multi-stage build.
  - Stage 1: `golang:1.21-alpine` to build binary.
  - Stage 2: `alpine:latest` to run binary.
  - Copy binary and static HTML/CSS/JS.
  - Expose port 8080.
- **docker-compose.yml:**
  - Service: `panji-mbg`.
  - Port: 8080:8080.
  - Volume: `./data:/app/data` (for sqlite db).
  - Nginx comment: "Configure Nginx to proxy / to this container".
